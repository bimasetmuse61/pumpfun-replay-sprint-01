A deterministic paper-trading bot for the pump.fun replay: it skips the launch pump (over before its 2-slot-late orders can fill) and rides only the slow grinders — curves whose real SOL reserve keeps growing steadily while the price holds near its high — with a small probe, a wide take-profit and a tight stop.

## Run it

```sh
node main.ts
```
